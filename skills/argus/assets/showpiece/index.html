Showpiece starters

Mechanisms to copy between the argus:copy-start <name> and argus:copy-end <name> markers, then redraw for the subject. Read references/showpiece.md first: it says which level a site gets and when each technique earns its place.

Each one registers what it moves on window.__argus, so shot.js --scenes, --timeline <name> and --arrival can step through it and write a contact sheet.
