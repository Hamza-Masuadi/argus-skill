# Tells

Last revised: 2026-11. These drift as models change.

A tell is a choice that appears because it is the default, and readers have learned to recognise it. None of these is forbidden. Each is fine when the brief or the existing system asks for it. The question to ask of every one found: was this chosen, or did it just arrive?

After replacing a tell, check the replacement is not simply the next most common default. This is the known weakness of any list like this one: avoiding the listed looks tends to produce the next most common look, which then becomes the new cliché. The list cannot fix that on its own. What does is a direction taken from the specific subject, a reference from the user, and the "Tried" log in `DESIGN.md`.

If the user asked for something on this list, build it well and do not flag it.

## Whole-page looks

Landing in one of these without being asked means the direction step was skipped:

| Look | Instead |
|---|---|
| Cream background, serif display, terracotta accent | Draw palette and type from the subject's world (see `create.md`) |
| Near-black background with a neon or acid accent and glow | Choose dark only when the place of use calls for it; flat accent, no glow |
| Purple-to-blue or purple-to-pink gradients | One flat accent drawn from the subject |
| Newspaper styling: hairlines, italic serif, small mono labels | Hierarchy by size and space; mono only for actual code or data |
| Thick borders and hard offset shadows on everything | Borders and shadows only where they separate something |

## Layout

| Tell | Instead |
|---|---|
| Centred hero: badge, headline, subhead, two buttons | Lead with the product, a real image or the content itself; one primary action |
| Three equal cards, each icon + heading + two lines | Fewer, unequal items; or a list, a comparison, a real screenshot |
| Small all-caps label above every heading | Let the heading stand alone. (A label that is real information, such as a car's make above its model or a category above a product name, is not this tell.) |
| Row of big statistics with invented numbers | Real figures with sources, or leave it out |
| Every section in a rounded card | Space and alignment; boxes only for things that are objects |
| `01 / 02 / 03` numbering on content that is not a sequence | Number only real steps |
| Logo strip of invented customers; invented testimonials | Real ones, or none |

## Detail

| Tell | Instead |
|---|---|
| Emoji used as icons | One icon set, used consistently, or no icons |
| Gradient-filled headline text; one coloured word in a headline | Solid text; emphasis by wording |
| Glass blur as decoration | Solid surfaces; platform materials only where the platform uses them |
| Coloured left border on callout cards | Background tint or an icon |
| Pill-shaped everything | One radius language chosen in the direction |
| Arrow after every link | Plain links |
| Pulsing "live" dot with nothing live behind it | Remove it |
| Every section fades up on scroll | One authored moment; otherwise content is simply there |
| The first sans-serif that comes to mind, used for everything | A family chosen for the subject, or the platform's system font used deliberately |

## Copy

| Tell | Instead |
|---|---|
| "Elevate", "seamless", "unlock", "supercharge", "effortless", "reimagine" | Say what the product does, with a verb and an object |
| Three-part rhythm in every line ("Fast. Simple. Secure.") | One specific claim |
| "It's not just X, it's Y" | State Y |
| Headlines that would fit any company | Name the thing, the user or the result |
| "John Doe", "Acme Inc.", round numbers like 10,000 | Plausible, specific stand-ins, marked as assumed |
